## 当天关键发现
1. **话题标签编译劣化风险**：
   - 当文章末尾存在 `#话题#` 格式标签且紧随换行时，通用 Markdown 编译器极易将其错误编译为 `<h1>` 或 `<h2>`，触发头条编辑器红杠大标题样式。
   - 包含逗号或标点的话题（如 `#年少吃苦和年老吃苦,哪一个更苦?#`）若正则限制过严会被截断或忽略。
2. **移动端预览弹窗指针拦截**：
   - 头条新版发文流程在点击“发布”后会弹出手机端阅读预览弹窗，弹窗遮罩可能拦截 Playwright 的标准元素点击，导致等待确认发布超时。
3. **正文有配图时的封面插槽漏填**：
   - 原发文策略判定“若正文有插图则不单独传封面”，但头条平台发布前强制校验“* 展示封面”必须有图，若平台未从正文自动提取，必须具备插槽自愈上传机制。
4. **AntiGravity 定时调度机制对齐**：
   - 侧边栏的 `Scheduled Tasks` 菜单与内核底层 `schedule` API 完全同构，需使用简洁规范的 Prompt 挂接 `python manage.py radar` 形成每日 09:00 / 15:00 准时提醒。

## 异常与根因
1. **封面插槽留空导致发布校验拦截**：
   - 直白根因：头条号富文本编辑器在部分网络情况下未能自动抓取正文第一张图作为展示封面，导致校验红字提示“请设置封面”。
   - 证据路径：`scripts/publisher.py#L425-L450`
   - 下一步建议：在 `publisher.py` 中增加封面插槽非空检查，若为空则自动上传同目录归档的 `cover.jpg`。
2. **手机预览弹窗发文按钮点击穿透受阻**：
   - 直白根因：模态预览遮罩层在动画期间阻挡了合成鼠标事件（`pointer-events`），引发等待微超时。
   - 证据路径：`scripts/publisher.py#L480-L510`
   - 下一步建议：引入双轨机制，先尝试常规点击，超时则直接执行原生 JS 注入穿透触发。
